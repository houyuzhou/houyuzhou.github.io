# houyuzhou.github.io

Personal homepage of Houyu Zhou, served by GitHub Pages at <https://houyuzhou.github.io>.

The site is plain static HTML with no build step:

- `index.html`: all page content
- `style.css`: layout, colors (light and dark) and fonts
- `images/`: portrait and favicons
- `.nojekyll`: tells GitHub Pages to serve the files as they are, without running Jekyll

To preview locally, open `index.html` in a browser. To update the site, edit `index.html` and push to `main`.
